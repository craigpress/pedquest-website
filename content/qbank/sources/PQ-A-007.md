## Where each fact came from

- Suppression ratio defined as percentage of time below a prespecified amplitude, displayed as a running average — Benedetti 2023, Amplitude-Focused Trends, item 3.
- "several minutes of EEG need to be collected to display the initial trends" — Benedetti 2023, Limitations of qEEG. This is the source for the statement that the trend inflection lags the true dose change.

## Judgment calls
- **The answer region derives from the spec, not from a hand-drawn mark.** point_to_feature.target_event is index 0, the single sedation_change event at at_min 150.0, and target_panel is suppression_ratio_L. The spec contains exactly one event, so the correct region is unambiguous.
- Tolerance is set to 0.04 (the schema default) rather than tighter, because the trend ramps over 15 minutes on a 360-minute axis and a learner clicking anywhere on the leading ramp should be credited.
- annotations is deliberately empty, matching the vignette premise that the dose change was never annotated. If an editor adds an annotation the item breaks.
- No quantitative accuracy claim is made, so no numeric sourcing is required beyond the trend definition.
